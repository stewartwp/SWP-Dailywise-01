# 每日智记 1.0 — iPhone 独立安装版

## 这是什么
可安装到 iPhone 主屏幕的 PWA（渐进式 Web App），无需 App Store。支持：
- 工作和生活分开记录，可写详情、项目标签；
- 新建待办，指定截止时间，标记完成；可设置每天、每周、每月重复（完成时生成下一次任务）；
- 查看已到期/即将到期事项；单条待办导出日历 `.ics`（默认提前 15 分钟提醒）；
- 标题、内容、项目标签全文查询，领域/状态筛选；
- 自动生成本周、上周、本月、上月报告，分工作/生活显示；可复制；
- 可选私有 AI 服务对总结进行语言润色；
- JSON 备份、合并导入和 CSV 导出；离线运行。

## iPhone 安装（推荐 GitHub Pages）
**注意：解压 ZIP 到 iPhone 后直接点 index.html 只能临时预览，不具备完整 PWA 安装能力。必须部署到 HTTPS 网站。**

1. 电脑打开 https://github.com，新建一个 public repository（例如 `dailywise`）。不要在仓库中上传个人工作日志、API 密钥或银行数据。
2. 将本 ZIP 内 `dailywise_app` 文件夹中的 `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png` 上传到仓库**根目录**（无需上传 AI Worker 或敏感资料）。
3. GitHub 仓库 Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save。
4. 等网站部署生效，访问 `https://你的用户名.github.io/dailywise/`。页面必须能正常加载。
5. 在 iPhone 的 Safari 打开这个网址 → 分享按钮 → **添加到主屏幕** → 添加。
6. 从手机主屏幕点击「每日智记」使用。进入设置 → 导出 JSON，建议每周备份到自己控制的安全位置。

也可部署到任何支持 HTTPS 的静态网站服务。GitHub Pages 部署的是**公开代码**，但 App 的记录默认仅存在个人设备浏览器的 localStorage，不会同步到 GitHub。

## 使用
1. 右下角 `＋` 新增；选择工作/生活、日常记录/待办，填写标题，必要时加详情、项目标签和截止时间。
2. 首页显示近期记录和截止事项；待办页勾选完成，重复任务会自动生成下一个周期的待办。
3. 到期任务点击「日历」生成 `.ics`；请使用系统支持的方式将文件导入 iPhone 日历，并核对事件时间及通知。iOS 上文件导入行为与系统版本有关：如直接下载未弹出导入，可以通过文件/邮件/日历兼容客户端打开 `.ics`。每条任务导出的是**当次日历事件**，在 App 中修改或重复生成任务并不会自动修改已导入的日历事件。
4. 查询页按关键词/领域/状态查找；总结页切换周期、范围，点击复制。
5. 设置页导出备份，换设备后导入；**不会自动跨设备同步**。

## 非常重要：提醒的真实边界
- 本版本到期提醒是 **打开 App 时提示**，不是后台推送。iPhone 锁屏或关闭 App 后，网页不能可靠按时提醒。
- 要获得锁屏系统级提醒，请导出 `.ics` 并导入系统日历，确认日历通知权限开启。
- 后续升级可加入服务器计划任务 + Web Push + iOS 推送订阅，实现全自动后台提醒；需要额外的服务端、订阅权限和专门的手机测试。

## AI 总结的真实边界
- 默认周报/月报是**本机规则整理**，不会调用 AI，也不会杜撰未记录事项。
- 真正 AI 润色需自行部署 `ai-worker.js` 到 Cloudflare Workers，并设置服务端 Secret `OPENAI_API_KEY`，环境变量 `ALLOWED_ORIGIN` 为托管网址的精确**源**（例如 `https://username.github.io`，不是带路径的网址）。还可以设置 `OPENAI_MODEL`。
- 在每日智记设置输入 Worker HTTPS 地址，点击总结页 AI 润色。它会把**当前汇总文本**发送至 Worker / AI API，执行前会弹出确认。
- 请为公开 Worker 配置 Cloudflare Access / 限流 / 配额控制。单纯浏览器跨域策略不是身份鉴权；任何能向 Worker 发请求的人都可能尝试消耗 API 费用。
- API 使用可能产生额外费用。**不要把 API Key 直接粘贴到前端代码或网页输入框，也不要上传未经批准的公司敏感信息。**

## 数据安全与技术限制
- 记录保存在浏览器 localStorage，未加密、无法跨设备同步；清除网站数据、浏览器卸载、设备遗失可能丢失数据。敏感信息应避免录入，尤其是银行客户信息、账号、凭据、审计证据、配置、日志。
- 本版本无账户认证/云端同步；不建议代替机构正式工单系统、业务系统或审计原始记录。
- 月度日期统计按当前设备本地时间计算。周从周一开始。
- 数据量适合个人轻量使用；记录数量大、多人同步或更高安全需求时应升级为加密数据库、登录及受控同步。
- CSV 能用于 Excel。 JSON 备份用于本 App 数据恢复。

## 开发文件
- `index.html`: 页面结构
- `styles.css`: iPhone 样式
- `app.js`: 记录、任务、搜索、报告、备份、提醒导出
- `sw.js`: 离线缓存
- `manifest.webmanifest`: 主屏幕安装配置
- `ai-worker.js`: 可选独立后端，不要直接当网站静态文件提供服务
